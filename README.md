# Casa Montana Vlašić

Website for Casa Montana, mountain apartments on Vlašić ([@casa.montana.vlasic](https://www.instagram.com/casa.montana.vlasic/)).

**Live:** https://casamontanavlasic.com

## What's inside

- Illustrated first screen with a winter and summer switch
- Apartments, gallery, amenities and location
- Custom date picker and a booking request that opens Viber or WhatsApp with the message already written
- Bosnian, English and German

## Tech

Plain HTML, CSS and JavaScript, no framework and no build step. Hosted on Cloudflare Workers. All apartment data is in `data/vikendica.js`.

## Run locally

```
node serve.mjs
```

Then open http://localhost:8080.
